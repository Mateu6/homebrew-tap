# Homebrew tap

Casks for [Upthere](https://github.com/Mateu6/upthere), the native macOS notch
app for Now Playing and Claude Code activity.

```bash
brew install --cask mateu6/tap/upthere
```

Upthere updates itself (Sparkle); `brew upgrade --cask upthere` works too.
The cask is bumped automatically when a new Upthere release is tagged.
